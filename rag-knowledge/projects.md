# Projects

## WildCard AI

WildCard AI is an AI-powered application built using a Spring Boot backend and React frontend.

The project explores LLM integration, conversational AI, embeddings, and Retrieval-Augmented Generation (RAG).

The application uses an LLM to understand user questions and generate relevant responses.

## KaasuTracker

KaasuTracker is a smart expense tracking application.

The application uses Flutter for the frontend and Spring Boot for backend services.

It integrates with PostgreSQL through Supabase.

The application allows users to record expenses and analyze spending patterns.

AI-based expense analysis and categorization are part of the planned functionality.
